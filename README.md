# Network CIDR Toolkit

Python toolkit for IPv4 subnet calculations and CIDR training.

## Features

- IPv4 subnet calculator
- CIDR training application
- Network address calculation
- Broadcast address calculation
- Host range calculation
- Gateway suggestion

## Technologies

- Python 3
- ipaddress
- CLI

## Included projects

- calculator_network_CIDR.py
- Trening-network-cidr.py

## Example

Input:

192.168.10.55/24

Output:

Network: 192.168.10.0

Broadcast: 192.168.10.255

Host range: 192.168.10.1 - 192.168.10.254
